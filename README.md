# Armando Alkadi — نسخة عرض تفاعلية (UI/UX Demo)

واجهة أمامية كاملة لموقع مكتب عقارات للإيجار الشهري والسنوي في الإمارات.
**لا يوجد باك اند ولا قاعدة بيانات** — كل البيانات وهمية وكل التفاعلات تعمل على
حالة محلية في المتصفح، والغرض هو موافقة العميل على الشكل والتجربة.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
```

أوامر أخرى:

```bash
npm run build    # نسخة إنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
npm run check    # فحص أنواع TypeScript
npm test         # فحص دخاني يفتح كل صفحة ويشغّل كل تفاعل رئيسي
```

## الصفحات

| الرابط              | الصفحة                                   |
| ------------------- | ---------------------------------------- |
| `/`                 | الرئيسية                                 |
| `/properties`       | كل العقارات + البحث والفلاتر (في الرابط) |
| `/property/:id`     | تفاصيل عقار (مثال: `/property/AK-102`)   |
| `/contact`          | تواصل معنا                               |
| `/admin`            | لوحة المكتب — نظرة عامة                  |
| `/admin/properties` | إدارة العقارات                           |
| `/admin/inquiries`  | الاستفسارات                              |
| `/admin/media`      | مكتبة الصور                              |
| `/admin/settings`   | إعدادات الموقع (عرض فقط)                 |
| `/admin/users`      | المستخدمون (عرض فقط)                     |

## أين أغيّر البيانات؟

| ماذا                                          | الملف                          |
| --------------------------------------------- | ------------------------------ |
| اسم المكتب، الشعار، الهاتف، واتساب، الإيميل    | `client/src/config/site.ts`    |
| عناوين الصفحات ووصفها (SEO)                   | `client/src/config/site.ts`    |
| العقارات، المناطق، أنواع العقارات، المرافق    | `client/src/data/properties.ts`|
| الاستفسارات والإشعارات وأرقام لوحة المكتب      | `client/src/data/admin.ts`     |
| ملف الشعار نفسه                                | `client/public/brand/`         |
| الألوان والخطوط والتنسيق                       | `client/src/index.css`         |

## ملاحظات مهمة

- **الشعارات رسمية، لا تستبدلها**: ملفات `client/public/brand/aahh/` نسخ من ملف الهوية الرسمي
  (AAHH_Brand_Package) بعد تنظيفها بـ svgo فقط (حُذفت بيانات C2PA الوصفية)، وتُرسم مطابقة للأصل
  بكسلاً بكسل. ممنوع إعادة رسمها أو تلوينها أو إضافة أي تأثير عليها (قواعد README الهوية).
- **التخزين محلي في الذاكرة فقط**: أي عقار تضيفه أو تحذفه من اللوحة يختفي عند
  تحديث الصفحة. هذا مقصود في مرحلة الديمو.
- **الصور من Unsplash** عبر روابط مباشرة — تحتاج إنترنت للعرض.
- **الصفحات الموسومة «قريباً»** (إعدادات الموقع، المستخدمون، رفع الصور) معروضة
  عمداً بشكلها النهائي لكنها تحتاج باك اند لتعمل فعلياً.
